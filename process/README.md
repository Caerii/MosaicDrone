# Process and QC

## Work instructions
- Include: scope, tools, safety, steps with photos, torque/adhesive/weld schedules
- Template fields: WI-ID, Rev, Author, PPE, Procedure, Checkpoints

## QC checklists
- Incoming: verify MPN, count, visual, certificates
- In-process: dimensions, torque, fit, electrical tests
- Final: functional tests, telemetry, cosmetic
- Template fields: QC-ID, Rev, Lot, Inspector, Results, Deviations

## Records
- Batch logs; calibration; traceability with lot codes and serials
