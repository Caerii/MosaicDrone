# Operations and SOPs

## Procedures
- Preflight: hardware inspection, battery check, link test, sensor calibration
- Launch: safe zone clearance, arming, takeoff protocol
- Docking/Recharge: announce intent, approach speeds, pre-charge, verification
- Fault handling: hover/freeze, guided land, perch to nearest dock
- Shutdown: power down order, data sync, inspection

## Training
- Roles: operator, maintainer, safety observer
- Certification: checkrides; recurrent training intervals

## Incident response
- Immediate E-stop if needed; secure site; record data; report within defined time
- Root cause analysis; corrective actions; update SOPs
